## ✨ 핵심 기능 및 특징 (Key Features)

### 1. [핵심 기능 1: 인터랙티브 스토리텔링]
- 플레이어 선택지에 따른 멀티 엔딩 분기 구조 구현

### 2. [핵심 기능 2: 익숙한 크레인 게임 기믹]
- 일본 크레인 게임에서 가져온 기믹
- 현지에서 느낀 감상을 최대한 비슷하게 재현
